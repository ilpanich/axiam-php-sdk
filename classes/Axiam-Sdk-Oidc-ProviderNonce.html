ProviderNonce.php : 25

The pair a native sign-in needs (CONTRACT.md §37.4): the **raw** nonce AXIAM wants, and the **hashed** one the provider's SDK wants.

Give self::$hashed to the provider's SDK as its nonce; the provider's ID token then carries that hex string in its nonce claim. Give self::$raw to AxiamClient::loginWithProviderIdToken(), which sends it byte for byte — the server hashes it and compares. Swapping the two is invisible at the call site and comes back as the same generic invalid_grant as every other refusal, which is why this pair exists.

$raw is a credential (§37.6): with the provider's token it signs the user in. It is a Sensitive, so var_dump(), print_r(), json_encode() and string conversion never show it; hold it only for the length of the attempt. $hashed is not secret — it travels to the provider and into the token.
