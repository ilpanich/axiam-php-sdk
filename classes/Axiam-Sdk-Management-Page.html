One page of a paginated §27 list response (CONTRACT.md §27.4 rule 4).

$total is the server's count of everything matching the query, NOT count($this->items). Confusing the two is the single most common way a management client silently processes only the first fifty of four hundred objects, so this class keeps them as separate, separately-named properties and never derives one from the other.

A bare JSON array response is NOT a page and is never modelled as one (§27.4 rule 4); the generated surface returns those as a plain list<T>.
