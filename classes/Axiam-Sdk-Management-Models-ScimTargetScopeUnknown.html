ScimTargetScopeUnknown.php : 20

A {@see ScimTargetScope} whose `type` this SDK's copy of the spec does not list.

Decoding one never fails, so a record using a newer variant still lists and reads. It keeps the type and nothing else of what the server sent (CONTRACT.md §31.2, §34.2 P12.1). It can never be sent: self::toArray(), the wire form, throws, because re-sending a body this SDK cannot represent would silently rewrite it; self::jsonSerialize() renders the discriminator, so a log line never fails (§34.2 P12.2).
