SsfUnjudgedEvent extends TelemetryEvent
in package

SsfUnjudgedEvent.php : 16

Emitted when `ssf.poll` returns normally leaving at least one SET unjudged (CONTRACT.md §19.1, contract 1.60; §34.2 P1).

An unjudged SET raises nothing: poll() returns what it judged and the transmitter offers the rest again. Without this event a JWKS or replay-store outage would be invisible to the caller for as long as some SET of each batch still verifies. It carries a count and a category — never a jti, never a SET.
